# MetaVul: Supplementary Materials

Supplementary materials for the paper *MetaVul: Agentic Harness Discovery for Vulnerability Detection*.
The paper refers to these sections as Supp. S1 to Supp. S12. Each section is a separate PDF, and
[MetaVul_supplementary_materials.pdf](MetaVul_supplementary_materials.pdf) contains all of them in one file.
References such as "Sec. 3" or "Fig. 3" point to the main paper.
